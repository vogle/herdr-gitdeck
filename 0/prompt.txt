**`src/updater.ts`**:
- `VERSION` comes from `declare const __GITDECK_VERSION__`.
- State file: `${home()}/.config/herdr-app/mods/.gitdeck-update.json` storing `{checkedAt}`, shared by all copies of the mod.
- `checkForUpdate()`:
  - claims the check by writing the state file first;
  - fetches the API with headers `Accept: application/vnd.github+json` and `User-Agent: gitdeck`;
  - if the release is newer, sets module-level `pending` and calls `notify({title:"gitdeck X is out", body:"You have V. Click to update.", level:"info", action:{name:"gitdeck.update"}})`.
  - No `timeout` is set on the notify call.
- `installUpdate()`:
  - runs `exec("sh", ["-c", INSTALL, "gitdeck-update", release.asset])`;
  - INSTALL is a shell script mirroring `dev-install.sh`: `curl -fsSL --max-time 20` into `mods/.gitdeck-download`, `tar -xzf ... gitdeck`, check that `main.js` and `mod.json` exist, stage in `.gitdeck-stage`, run `herdr-app check` if it is on PATH, then `mv` swap via `.gitdeck-old`;
  - the URL is passed as `$1`;
  - on success it notifies "gitdeck updated to X" (success); on failure, "gitdeck update failed" with the reason and "Your version is unchanged." (error).
