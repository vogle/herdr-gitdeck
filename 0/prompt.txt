## Question answered between tasks
The user asked how Review splits code and tests and whether it works for all languages. Answered from `src/core/reviewOrder.ts` and checked by running `reviewGroup` on sample paths.

**How it works:** it is path/name-based only.
- `TEST_FOLDER = /(^|\/)(tests?|__tests__|spec)\//`
- `TEST_NAME = /([._]test|\.spec)\.[^/.]+$/`
- Then `fileKind` code/terminal → "code", else "other".

**Gaps it misses:**
- Python `test_foo.py` outside a tests folder
- Ruby `_spec.rb` outside `spec/`
- `FooTest.java` / `FooTests.cs` / `FooTests.swift` outside a test folder
- Capitalized `Tests/`
- Rust inline tests
- `.m`, `.R`, `.hs`, `.clj` land in "other"

The user was offered extending this. No decision was made.
