2. Key Technical Concepts:
   - Herdr mods run in QuickJS: no Node APIs, and no `URL` global.
   - gpui-kit elements, plus `h_flex`, `v_flex` and `v_virtual_list` from gpui-base.
   - Virtual list rows can't hold handlers. Use the list-level handlers instead:
     - `on_item_click(key, cx)`.
     - `on_item_secondary_click(key, event: MouseButtonEvent, cx)`, which fires on a right-press over a row.
     - The press then bubbles to the elements around the list. An element there gets its own `local_position` via `on_mouse_down("right", e => e.local_position)`.
   - `MouseButtonEvent` has `{ button, click_count, position, local_position?, bounds?, modifiers }`.
   - `MouseButton` is `"left" | "right" | "middle"`.
   - `on_mouse_down_out(handler)` closes a surface you drew yourself when the user presses outside it.
   - There is no built-in menu component, so the menu must be drawn by hand as an absolute overlay.
   - Verification loop:
     1. `pnpm verify` for typecheck, tests, coverage and build.
     2. `pnpm -s dev` to install the mod.
     3. `herdr-app status` for errors.
     4. `herdr-app shot <file>` for a screenshot.
     5. `herdr-app do gitdeck.tab:history` to switch tabs.
   - Selecting a commit needs a click. Use `orca computer click --app dev.herdr.app --x <pt> --y <pt> --no-screenshot --json`.
     - Window coordinates are in points: the window is 1920×1050 at (0,30).
     - Screenshot pixels are 3840×2100, so a point is the original pixel divided by 2.
     - In the History tab, the "fix: blame a deleted…" row is at about (1595,287).
     - With a commit open, the parent link is at about (1521,329).
   - Crop screenshots with `sips -c 1000 1000 --cropOffset 50 2840 in.png --out out.png`.
   - Reinstalling with `pnpm dev` reloads the mod and resets it to the Changes tab.
